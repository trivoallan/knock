# Reference

Reference for knock's published contracts. The schema pages, the configuration table and the CLI
page are generated by `make reference`; CI fails if they drift from the code.

- [Published schemas](schemas/README.md) — the policy, scan-attestation, plan, staging and audit contracts, each with its `.schema.json`.
- [Configuration](configuration.md) — every `KNOCK_*` variable, its type and its default.
- [Command Line Interface](command-line-interface.md) — every `knock` command and option.
- [SARIF ingestion profile](sarif-ingestion-profile.md) — the SARIF 2.1.0 contract any analyzer writes against so knock classifies its results correctly: vulnerability findings into `vuln.*`, governance verdicts into `policy.*`, keyed on `result.kind`.
- [Glossary](glossary.md) — knock's domain vocabulary: the stamp, provenance, SBOM, transform, and lifecycle terms, each linked to its full treatment.
- [Example policies](examples/README.md) — a catalog of runnable `MirrorPolicy` files, one capability each.
