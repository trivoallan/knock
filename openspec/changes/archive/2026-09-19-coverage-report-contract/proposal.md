## Why

`knock audit --signed --sbom` with `KNOCK_LOG_FORMAT=json` is already consumed as an inventory of
placed images: a downstream CronWorkflow (observed against 0.11.0 in a kind cluster on 2026-09-19)
keeps `covered && signed && sbom` and reads `image_ref`, `digest` and `policy`, then ships each
image's CycloneDX SBOM attestation to an SBOM platform. The output works, but it is not a published
contract: there is no schema on the reference site, no version marker, and nothing tells a consumer
which SBOM formats an image carries — so the consumer pins knock by digest and re-guards fields in
its own tests.

## What Changes

- **Publish the coverage report schema** at `docs/reference/schemas/coverage-report.schema.json` with
  a rendered reference page, generated by `make reference` from the Pydantic model like the other
  published schemas, and guarded by a drift test plus the existing CI reference diff.
- **Version marker**: the JSON report gains `apiVersion: knock.io/v1alpha1` and
  `kind: CoverageReport`, the convention the `ReconcilePlan` (`--plan-out`) already uses. Within an
  `apiVersion` only additive changes are allowed; a removal, rename, or change of meaning bumps it.
- **`sbom_formats`** per outcome when `--sbom` is set: the syft format names (`spdx-json`,
  `cyclonedx-json`) whose SBOM referrer was found on the image. The `sbom` boolean is kept with its
  current meaning.
- **CLI reference**: `knock audit`'s help (and so the generated `command-line-interface.md`)
  documents the JSON output, its fields and the compatibility rule.
- Additive only: no field is removed or renamed; text output is unchanged.

## Capabilities

### New Capabilities
- `coverage-report`: the JSON document `knock audit` emits — its version marker, its fields
  (including `sbom_formats`), its published schema and its compatibility rule.

### Modified Capabilities

## Impact

- Use case: `knock/use_cases/audit.py` (`CoverageReport` version fields, `CoverageOutcome.sbom_formats`,
  per-format SBOM probe).
- CLI: `knock/cli/audit.py` (serialize by alias; help text documents the JSON output).
- Docs: `scripts/gen_reference.py` (new schema slug), `docs/reference/schemas/coverage-report.*`,
  `docs/reference/command-line-interface.md` (regenerated).
- Tests: `tests/unit/use_cases/test_audit.py`, CLI audit tests, a schema drift test.
- One extra `list_referrers` call per covered image under `--sbom` when the first format is found
  (all formats are probed instead of stopping at the first).
- No new port, adapter or external system; the C4 model is unchanged.
